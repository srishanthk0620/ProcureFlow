# ProcureFlow Development Roadmap

## P0 — Foundation
Repository, architecture, rules and verification protocol.

## P1 — Application Scaffold
Frontend/backend base applications and developer environment.

## P2 — Core UI / Demo Shell
Role selection, navigation and polished visual foundation.

## P3 — Farmer Domain
Farmer profiles, delegation/Farmer Circle and consignments.

## P4 — Centre + Resource Domain
Centres, stages, resources, capacity and equipment state.

## P5 — Scheduling Engine
Service-time estimation, capacity constraints,
resource conflict prevention and appointment generation.

## P6 — Booking Experience
Centre comparison, recommendations, booking,
token generation and explanations.

## P7 — Centre Staff Workflow
Check-in, quality, weighing, unloading and completion.

## P8 — Live Queue
Queue state, ETA calculation and realtime updates.

## P9 — Disruption Recovery
Equipment failures, delays, no-shows,
recalculation and controlled rescheduling.

## P10 — Admin Dashboard
Network monitoring, analytics, bottlenecks
and simulation results.

## P11 — PWA / Offline
Installability, caching, offline states
and safe queued requests.

## P12 — Demo Communication
Simulated SMS, automated call and multi-channel demonstrations.

## P13 — Judge Demo Mode
Seeded scenarios, disruption simulation,
role shortcuts and polished demo flow.

## P14 — Final Testing / Polish
Performance, responsiveness, accessibility,
error states and presentation polish.

- IVR / missed-call integration
- BHASHINI evaluation

- PACS/CSC integration
- FPO integration
- government authentication integrations
- real payment integration
